# Retail Analytics Performance Dashboard

## Project Overview
An interactive Power BI dashboard designed to analyze retail performance, tracking key sales metrics, categorical distributions, and monthly revenue trends. 

## Key Performance Indicators (KPIs)
* **Total Revenue:** $29.14M
* **Total Profit:** $9.20M
* **Total Orders:** 30K
* **Total Customers:** 9K

## Key Insights
* **Top Categories:** *Sports & Outdoors* ($10.4M) and *Electronics* ($10.3M) drive the vast majority of sales volume, significantly outperforming *Clothing* and *Beauty*.
* **Sales Trends:** Revenue experienced strong cyclical peaks, hovering consistently between $20K and $45K monthly, with sharp, periodic demand spikes.

## Technologies Used
* **Power BI Desktop:** Data Modeling, DAX (Data Analysis Expressions), and Visualizations.
* **Power Query:** Data cleaning and schema structuring.
